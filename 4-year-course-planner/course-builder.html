Define the courses, prerequisites, and graduation-requirement matches your school uses, then generate the student planner file.

Courses

These are pre-loaded from the Tennessee State Board Graduation Permissions & Substitutions Policy 3.103 and the WCS High School Program Planning Guide. Turn courses on or off, edit any field, or add new courses. Only courses set to Offered appear in the student planner.

Generate the Student Planner

1. Save your setup

Save a project file so you can reload and keep editing later. Your work is also auto-saved in this browser.

2. Build the planner

Creates wcs-planner.html - a single file students download and run locally. It contains only the courses you marked Offered, plus your school settings.

The planner has no internet requirement and stores nothing online. Students keep their plan by exporting a PDF from it; next year they upload that PDF back into the planner to restore their completed classes.

Graduation requirements this course can satisfy

Check every requirement this course is eligible for. The planner will apply it to only one.

Prerequisites

Add one row per required item. Within a row, pick every course that would satisfy it (student needs any one). Check “may be taken at the same time” if concurrent enrollment is allowed. Leave empty for no prerequisite.
