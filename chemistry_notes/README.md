# Chemistry notes

Guided notes for the courses, as Word documents, with the code that builds the honors packets.

| Folder | What is in it |
| --- | --- |
| `Honors Chemistry/Student Notes Packets/` | Units 0 to 8, each as a `STUDENT NOTES` packet (blank, to fill in) and a `TEACHER EDITION` (same pages, answers filled in, teacher notes). Unit numbers follow the course order: 0 Measurement and Math Skills, 1 Atomic Structure, 2 Electrons and Periodic Trends, 3 Chemical Bonding, 4 Chemical Reactions, 5 Moles and Molar Quantities, 6 Stoichiometry, 7 Gases, 8 Intermolecular Forces. Only Reactions (4) and Moles (5) are confirmed; Gases and IMFs may move again. |
| `Honors Chemistry/NOTES-PACKET-GUIDE.md` | The rules for building a packet: length, layout, building blocks, writing space, teacher edition, style. Includes the plan for the Gases unit. |
| `Honors Chemistry/Sample Tests/` | The review test given right before a unit test: 20 multiple choice (two columns) plus 4 free-response questions, 4 pages, with a separate teacher key. Unit 4 (Reactions) is the original example; Unit 5 (Moles) is built by `_packet_builder/make_unit5_test.py`, which computes every answer. |
| `Honors Chemistry/Pre Tests/` | Unit 5 (Moles) pre-test: 10 multiple choice questions on one page, spread across topics 5.1 to 5.7, modeled on the sample test but with different questions, plus a teacher key. Built by `_packet_builder/make_unit5_pretest.py`, which computes every answer. |
| `Honors Chemistry/Free Response Tests/` | Unit 5 (Moles) one-page free response test in three versions (A, B, C) plus one teacher key. Question 1: a transition metal heated in O₂ gives an oxide (masses, grams to atoms, empirical formula, balanced equation). Question 2: a hydrate lab (water lost and percent water, moles, x and name, error analysis). Each version has a different oxide (2:3, 2:5, 3:4) and hydrate (x = 2, 7, 6). Built by `_packet_builder/make_fr_tests.py`, which computes every answer. |
| `Honors Chemistry/Labs/` | Lab handouts, each with a student version and a teacher edition. Unit 5: empirical formula of magnesium oxide (Mg + O₂), built for one 47-minute period with pre-massed crucibles and ribbon: pre-lab, lab write-up and extension questions. Built by `_packet_builder/make_mg_lab.py`. |
| `Honors Chemistry/_packet_builder/` | The Python scripts that build a packet (`lib.py` helpers, `make.py` and `build_gases.py` for Gases, `make_moles.py`, `build_moles.py` and `figs_moles.py` for Moles, `figs.py` for the figures, `img/` for the images). They use the Unit 5 packet as a template and compute every answer in code. Needs python-docx, Pillow, NumPy and Matplotlib. |
| `Honors Chemistry/PDF Sources/` | The topic homework PDFs the packets follow. |
| `Honors Chemistry/Nomenclature/` | Nomenclature notes. |
| `AP Chemistry/Acids Bases and Buffers/` | Answer key with explanations for the Acid–Base and Buffer sample test (20 multiple choice, 5 free response), written the way College Board scoring guidelines expect, with suggested points, common errors and model sketches. Built by `_build/make_answer_key.py`. |
| `AP Chemistry/Thermochemistry and Free Energy/` | Condensed AP notes for the first part of thermodynamics (CED topics 6.1 to 6.9 and 9.1 to 9.6, stopping before electrochemistry): 9 sections, worked examples with work space, no fill-in-the-blank statements, and 20 warm-up multiple-choice questions at the back. Includes a teacher key with every example solved. Built by `_build/make_notes.py`, which computes every number. |
| `AP Chemistry/Thermochemistry and Free Energy/` (slides) | `AP Chem Unit 6 - ... - SLIDES.pptx`: an 83-slide animated PowerPoint that walks through the Unit 6 notes. Every example is solved step by step with one click per step (real stacked fractions), plus animated scenes (energy flow, reaction profiles, heating curve, bond breaking and forming, calorimeter, Hess's law cancellation, entropy and gas expansion, free-energy valleys, coupled reactions) and the 20 warm-ups with click-to-reveal answers. Speaker notes list every click. Built by `_slides/make_deck.py` (python-pptx plus hand-written animation XML in `_slides/anim.py`); set `DECK_FINAL=1` to draw each slide as it looks after its last click. |
| `AP Chemistry/Equilibrium/` | Equilibrium guided notes (student and key), a notes outline, ICE tables and K, and Le Chatelier's principle. |

**This repository is public.** The teacher editions and keys are readable by anyone who finds them. If the packets are meant to be seen
only by teachers, keep them out of a public repository.
